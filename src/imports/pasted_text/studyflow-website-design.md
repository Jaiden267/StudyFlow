Design a polished, modern, responsive website called **StudyFlow**, a fictional productivity platform that helps university students organise assignments, manage deadlines, plan study sessions, and monitor their academic progress.

The purpose of this project is to demonstrate strong Figma skills, including Auto Layout, reusable components, component variants, responsive design, prototyping, visual hierarchy, accessibility, and consistent UI design.

## Overall visual direction

Create a clean, professional SaaS-style website suitable for university students.

The design should feel:

* Modern
* Friendly
* Organised
* Trustworthy
* Easy to navigate
* Professional enough for a portfolio

Use a light interface with plenty of white space.

Suggested visual style:

* Primary colour: deep blue or indigo
* Secondary accent: purple
* Success colour: green
* Warning colour: amber
* Error colour: red
* Background: very light grey
* Cards: white with subtle borders and soft shadows
* Rounded corners: approximately 10–14 pixels
* Use a modern sans-serif font such as Inter
* Use simple line-style icons
* Avoid excessive gradients, glass effects, or decorative illustrations
* Maintain accessible colour contrast and readable text sizes

Use a desktop frame width of 1440 pixels and create mobile versions at 390 pixels wide.

# Responsive design

Create responsive mobile versions of:

* Landing page
* Navigation menu
* Log-in page
* Dashboard overview
* Assignments page
* Add-assignment modal

For mobile:

* Convert the desktop sidebar into bottom navigation or a slide-out menu
* Stack dashboard cards vertically
* Make tables display as cards
* Ensure buttons and input fields are touch-friendly
* Use at least 16-pixel body text
* Maintain clear spacing and readable layouts
* Avoid horizontal scrolling

Ensure that:

* Text has sufficient colour contrast
* Interactive elements have clear focus states
* Form fields have visible labels
* Error messages explain how to correct the problem
